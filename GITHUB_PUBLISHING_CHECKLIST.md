# GitHub Publishing Checklist

1. Copy `README.md`, `.gitignore`, and `docs/screenshots/` into the root of your project.
2. Compare the documented file names with your actual project files.
3. Add original terminal screenshots if you have them. The supplied panels are reconstructed evidence, not raw screenshots.
4. Review `requirements.txt` and make sure it contains the dependencies your scripts actually import.
5. Check that no API keys, passwords, personal tokens, `.env` files, or private data are included.
6. Do not upload `.venv/`, Spark `checkpoints/`, or unnecessary large files.
7. Create a public GitHub repository, then run the Git commands shown in the README publishing instructions in the chat response.
